# Chiara Pilates — demo sito

Landing page statica (HTML/CSS/JS, nessuna build). Apri `index.html` o servi la cartella:

```
python3 -m http.server 8000
```

- `assets/video/` video compressi (hero orizzontale + reel verticali)
- `assets/img/` immagini e poster
- Il modulo contatti apre WhatsApp con il messaggio precompilato.
